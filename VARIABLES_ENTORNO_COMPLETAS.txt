                              📋 INSTRUCCIONES DE USO
================================================================================

🔧 CONFIGURAR DESARROLLO:
1. Copia las variables de DESARROLLO
2. Crea el archivo .env.local en la raíz del proyecto
3. Pega las variables en el archivo
4. Ejecuta: npm run dev

🚀 CONFIGURAR PRODUCCIÓN:
1. Ve a https://vercel.com/dashboard
2. Selecciona el proyecto "lumo"
3. Ve a Settings → Environment Variables
4. Agrega cada variable de PRODUCCIÓN una por una
5. Asegúrate de seleccionar "Production" como environment
6. Ejecuta: npm run deploy

⚡ CONFIGURACIÓN AUTOMÁTICA:
- Desarrollo: npm run env:dev
- Producción: npm run env:setup:complete
- Verificar: npm run env:check
